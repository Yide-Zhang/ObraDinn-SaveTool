# Obra Dinn 存档工具

一个给《Return of the Obra Dinn》看存档、改存档的小工具。

打开后是一个和原生程序一样的窗口（其实是个本地网页），**完全离线** —— 不联网、不用注册、不上传任何东西，只在你自己的电脑上读写存档文件。

---

## 下载

到本仓库的 **Releases** 页面，挑对应平台的压缩包：

| 你的系统 | 下载 |
|---|---|
| Windows 10 / 11（64 位） | `ObraDinnSaveTool_Windows.zip` |
| macOS（Intel 芯片，M 系列用 Rosetta 也能跑） | `ObraDinnSaveTool_MacOS.zip` |

包里就一个程序，没有别的文件：Windows 是 `ObraDinnSaveTool.exe`，macOS 是 `ObraDinnSaveTool.app`。这篇说明就是全部文档。

---

## 在 Windows 上使用

解压后双击 `ObraDinnSaveTool.exe`，**不需要安装**。

**第一次打开被系统拦下？**

因为程序没有买代码签名，Windows 可能弹出「Windows 已保护你的电脑」。点「更多信息」→「仍要运行」即可。

如果还是不行：右键 exe → 属性 → 勾上底部的「解除锁定」→ 确定。

程序就住在你解压出来的那个文件夹里，存档库（`saves` 文件夹）和日志也生成在旁边。**整个文件夹拷到 U 盘或另一台电脑上照样能用。**

## 在 macOS 上使用

把 `ObraDinnSaveTool.app` 拖进「应用程序」文件夹。

**第一次打开被系统拦下？**

同样因为没有 Apple 开发者签名。任选一种：

1. 在 Finder 里**右键**点它 →「打开」→ 弹窗里再点「打开」（之后就能正常双击了）
2. 系统设置 → 隐私与安全性 → 拉到底部 →「仍要打开」
3. 打开「终端」跑一行：

   ```
   xattr -dr com.apple.quarantine /Applications/ObraDinnSaveTool.app
   ```

## 界面上能做什么

### 三张存档卡（P1 / P2 / P3）

对应游戏里的三个存档位。每张卡直接告诉你这份存档现在什么状况：解对了多少人、剧情走到哪一段、会走向哪种结局、主人公是男是女、解锁了多少章。

- **同步难度** —— 让这份存档对齐当前的游戏难度（见下面的「游戏安装目录 · 当前难度」）
- **导出到存档库** —— 把这份存档收进工具的存档库，随时取用
- **切换性别** —— 只影响游戏里对主人公的称呼，和玩法无关
- **下载** —— 存到电脑上的任意位置
- **详细信息** —— 展开看全部内容：文件位置、大小、修改时间、校验值，以及船上区和办公室区各解对了多少人、解锁了哪些章节、包裹 / 猴爪之类的进度标志

### 游戏安装目录 · 当前难度

页头那一行会显示「游戏安装目录」和「当前难度」。自动找不到时（游戏装在很少见的位置），点**选择…**手动指到游戏目录：

- Windows：选 **`ObraDinn.exe` 所在的文件夹**（例如 `…\common\ObraDinn`）
- macOS：选 **`Return of the Obra Dinn.app` 所在的文件夹**（`/Applications` 就行）

**为什么要管难度？** 游戏有 7 档难度（简单 → 硬核），不同档位下能解开的船员数量不一样。一份在低难度下玩的存档，扔进硬核档会卡死、**没法通关**。工具会在你装入存档前先把这件事查清楚：

> 检测到您的存档和当前游戏难度不匹配。是否同步？
> **否则您将无法通关！**

选「是」就把它对齐到当前难度（**动手前会自动备份**），选「否」照旧装入。槽位卡上的**同步难度**按钮可以随时对某一份存档做同样的事；本来就匹配的存档，点它只会提示一句，不会改动文件。

### 存档制作器

页头右上角的**存档制作器**会打开一张「闪回解锁全图」：图上一个圆点就是一次闪回。它从**刚上船**的空白存档开始，点黑色的**实心**圆点＝把这次闪回标成已看过，它场景里躺着的那几具尸体随之解锁；点错了用**撤销**退一步，**还原**回到刚上船的状态。

改完点**导出到存档库**，自制存档就会出现在主界面的「存档库」里，之后装到任意槽位即可；也可以点**下载**直接存到电脑上。图上还能用 － / ＋ / 适应 缩放。

> 这一页只从空白存档起步，不接受拖入别人的存档；点**返回**离开时会问一句「**离开后您的所有编辑都不会被保存**」，确认后才回主界面。

### 预制存档

工具自带 5 份现成的存档，一键装到任意槽位（装之前会先自动备份）：

| 名字 | 装上去是什么状态 |
|---|---|
| 坏结局存档 | 已经走到最后一步，离船就进最差的结局 |
| 中等结局存档 | 同上，但结局信件是中等口吻 |
| 好结局存档 | 已经拿到包裹，接下来可以走好结局 |
| 直接推理存档 | 所有现场都已经看过，可以立刻开始推理，不用重跑一遍剧情 |
| “船长干的”存档 | 专门用来拿「船长干的」成就 |

预制存档是**只读**的，删不掉也改不了；装到槽位之后就随你怎么改了。

### 备份

写入任何东西之前，工具都会先把原文件备份一份。游戏自己也会保留上一版的快照。这些在「备份」一栏里都能看到，随时可以一键还原回某个槽位。

## 常见问题

**关掉窗口了，程序是不是已经退出了？**

没有。关窗口不等于退出 —— 再打开一次也只是把窗口叫回来，不会重复启动。要真正退出，请点窗口里的「退出程序」。

**窗口没有铺满屏幕？**

窗口是在浏览器启动之后才最大化的，启动慢的时候会晚一两秒。

**提示找不到存档目录？**

先进游戏一次，让它把存档目录创建出来，再打开本工具。

**杀毒软件报警了？**

没有签名的免费小程序常被误报，放心加入白名单即可。

**出问题了，怎么排查？**

把日志发给作者：

- Windows：程序旁边的 `ObraDinnSaveTool.log`
- macOS：`~/Library/Logs/ObraDinnSaveTool.log`

## 使用前请注意

- 本工具会**真的修改游戏存档**。虽然每次写入前都会自动备份，还是建议你先手动把存档目录复制一份留着。
- 适配游戏的 **1.2.122** 版，其它版本可能对不上。
- 目前做不到：凭空造一份全新的存档；修改剧情推进类的进度。
